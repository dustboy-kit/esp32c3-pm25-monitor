DBK Bluetooth

เครื่องวัด PM2.5 DustBoy Kit รุ่นที่ไม่ต้องมี Wi-Fi: แฟลช อ่านค่า และอัปเดตเฟิร์มแวร์ ทั้งหมดจากเบราว์เซอร์ผ่าน Bluetooth

1 · แฟลชผ่าน USB 2 · อ่านค่าสด 3 · อัปเดตไร้สาย ข้อกำหนด ความปลอดภัย แก้ปัญหา
สถานะ: ยังไม่ได้ทดสอบบนบอร์ดจริง

เฟิร์มแวร์ 0.2.0-ble คอมไพล์ผ่านและขึ้นเว็บแล้ว (5 พ.ย. 2026) แต่ยังไม่มีใครแฟลชลงบอร์ด DBK แล้วลองอ่านค่าหรือ OTA จริง ใครทดสอบแล้วบอกผลในห้อง dustboy-kit จะอัปเดตกล่องนี้

แฟลชครั้งแรกต้องใช้สาย USB (ข้อ 1) บอร์ดที่ยังเป็นเฟิร์มแวร์ Wi-Fi หรือรุ่นก่อน 0.2.0-ble ไม่มี Bluetooth OTA ให้ใช้

เบราว์เซอร์นี้ไม่มี Web Bluetooth: ข้อ 2 และ 3 ใช้ไม่ได้ที่นี่ เปิดหน้านี้ใน Chrome หรือ Edge บนคอม/Android

1 · แฟลชเฟิร์มแวร์ผ่าน USB

ครั้งแรก และทุกครั้งที่บอร์ดบูตไม่ขึ้น ใช้ทางนี้ Chrome/Edge บนคอมเท่านั้น (Web Serial)

  1. เสียบบอร์ด DBK เข้าคอมด้วยสาย USB ที่ส่งข้อมูลได้
  2. กด "แฟลช DBK Bluetooth" เลือกพอร์ตของบอร์ด แล้วรอจนเสร็จ
  3. ถอดแล้วเสียบใหม่ จอจะโชว์ "Dustboy Kit For Kids" แล้วแถวบนมีไอคอน Bluetooth
dbk-ble.factory.bin · 0.2.0-ble · ESP32-C3

2 · อ่านค่าสดผ่าน Bluetooth

ค่า PM1 / PM2.5 / PM10 มาทุก 1 วินาที จากบอร์ดในระยะประมาณ 10 เมตร

  1. เปิด Bluetooth ของเครื่อง แล้วกด "เชื่อมต่อ DBK"
  2. เลือก DBK-xxxxxx (เลขท้ายตรงกับที่จอบอร์ด) แล้วกด Pair/เชื่อมต่อในหน้าต่างของ Chrome
  3. ค่าจะขึ้นด้านล่าง กด "ติดตั้งเป็นแอป" ถ้าอยากเปิดจากหน้าจอโฮม

3 · อัปเดตเฟิร์มแวร์ไร้สาย (OTA ผ่าน Bluetooth)

ส่งเฟิร์มแวร์ใหม่เข้าบอร์ดโดยไม่ต้องเสียบสาย ใช้ได้กับบอร์ดที่เป็น 0.2.0-ble ขึ้นไป ใช้เวลาราว 1–2 นาที

  1. เชื่อมต่อบอร์ดด้วยข้อ 2 ก่อน (ปุ่มเดียวกัน)
  2. เลือกไฟล์ .ota.bin หรือกด "ใช้ตัวล่าสุดจากเว็บ"
  3. กด "เริ่มอัปเดต" รอแถบเต็มและขึ้น OK บอร์ดจะรีบูตเองแล้วกลับมาโฆษณาชื่อเดิม
ไฟล์เฟิร์มแวร์ (.ota.bin)
รหัส OTA เป็นค่าคงที่ "dbk" และเปิดเผยใน repo สาธารณะ มันกันการส่งผิดบอร์ดเท่านั้น ไม่ได้กันคนที่อยู่ในระยะ Bluetooth ตั้งใจส่งเฟิร์มแวร์ของตัวเอง ถ้าจะใช้นอกห้องเรียน ให้รอเวอร์ชันรหัสต่อเครื่อง

OTA ปลอดภัยแค่ไหน

เขียนลง slot ว่าง บอร์ดมี 2 ช่องเฟิร์มแวร์ (app0/app1 ช่องละ 1.75 MB) ตัวที่กำลังรันไม่ถูกแตะระหว่างส่ง
ตรวจ SHA-256 และขนาดก่อนสลับ ครบและตรงจึงสลับช่องบูต ไฟล์ผิด หลุดกลางทาง หรือกดยกเลิก = บอร์ดยังเป็นเฟิร์มแวร์เดิม
ไฟล์ผิดชิปถูกปฏิเสธ image ของ ESPHome มี magic + chip id ตัวที่ไม่ใช่ ESP32-C3 จะถูก esp_ota_end ตีกลับ
ไม่มี auto-rollback ถ้าเฟิร์มแวร์ใหม่แฮชถูกแต่บูตแล้วค้าง บอร์ดไม่ย้อนกลับเอง ทางกู้คือแฟลช USB ข้อ 1 (ข้อมูลไม่หาย เพราะ DBK ไม่เก็บอะไรบนบอร์ด)
ครั้งแรกต้อง USB OTA ใช้ได้กับบอร์ดที่เป็น 0.2.0-ble ขึ้นไปเท่านั้น

แก้ปัญหา

ไม่เห็น DBK ในรายการอุปกรณ์

เช็คว่าจอบอร์ดมีไอคอน Bluetooth (ถ้าไม่มี = ยังเป็นเฟิร์มแวร์ Wi-Fi ให้ทำข้อ 1) · ปิดแอปอื่นที่ค้างเชื่อมต่อกับบอร์ดอยู่ (บอร์ดรับได้ 2 คนพร้อมกัน) · เข้าใกล้กว่า 5 เมตร · Android ต้องให้สิทธิ์ Location/Nearby devices กับ Chrome

กดเชื่อมต่อแล้วล้มเหลว หรือหลุดทันที

ปิด-เปิด Bluetooth ของเครื่อง แล้วลองใหม่ · ถ้าเคยจับคู่ไว้ในตั้งค่าเครื่อง ให้ลบ (forget) ก่อน · บนคอม Windows ต้องเป็น Windows 10 ขึ้นไปและมี Bluetooth 4.0+

OTA ค้างกลางทาง หรือขึ้น ERR

ERR sha mismatch = ไฟล์ไม่ตรง โหลดใหม่จาก "ใช้ตัวล่าสุดจากเว็บ" · ERR bad begin = รหัสผิดหรือรูปแบบไฟล์ผิด ใช้ .ota.bin ไม่ใช่ .factory.bin · ค้างที่ RX = ลิงก์หลุด กดยกเลิก เชื่อมต่อใหม่ เริ่มใหม่ (บอร์ดยังเป็นเฟิร์มแวร์เดิม) · ขึ้น OK แล้วบอร์ดไม่กลับมา = แฟลช USB ข้อ 1
