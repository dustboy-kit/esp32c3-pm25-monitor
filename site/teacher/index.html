DUSTBOY KIT · คู่มือผู้สอน

ก่อนสอน ต้องเตรียมอะไร

เช็กลิสต์สำหรับครู 1 ห้องเรียน ใช้เวลาเตรียมประมาณ 1 ชั่วโมง ก่อนวันสอน พิมพ์หน้านี้ติดไปได้ (Ctrl+P)

1 · ของในกล่อง (ต่อ 1 ชุด)

อุปกรณ์

  • บอร์ด ESP32-C3 SuperMini 1 ตัวมีพอร์ต USB-C บนบอร์ด
  • เซนเซอร์ฝุ่น PMS7003 1 ตัว พร้อมสายแพ 10 เส้นต้องใช้ไฟ 5V นิ่ง ๆ ต่อผิดขั้วเสียทันที
  • จอ OLED SSD1306 ขนาด 128×32 1 จอ (4 ขา: VCC GND SDA SCL)
  • สาย USB-C "สายข้อมูล" 1 เส้นสายชาร์จอย่างเดียวใช้แฟลชไม่ได้ ทดสอบก่อนทุกเส้น
  • บอร์ดทดลอง (breadboard) + สายจัมป์ หรือชุดที่บัดกรีมาแล้ว
  • อะแดปเตอร์ USB 5V ถ้าจะวางเครื่องไว้วัดต่อเนื่องหลังเรียน

ผังสาย: README › Hardware wiring (PMS7003 TX→GPIO6, RX→GPIO7, SET→GPIO5, RESET→GPIO8 · OLED SDA→GPIO9, SCL→GPIO10)

2 · คอมพิวเตอร์

เครื่องที่ใช้แฟลช

  • คอม Windows / Mac / Linux ที่มี Chrome หรือ EdgeiPad, มือถือ, Safari, Firefox ใช้แฟลชไม่ได้
  • 1 เครื่องต่อนักเรียน 2–4 คน (แฟลช 1 ชุดใช้เวลาประมาณ 2 นาที)
  • คอมต้องต่อ Wi-Fi วงเดียวกับที่บอร์ดจะใช้ขั้นตั้ง Kit ID คุยกับบอร์ดผ่าน Wi-Fi
  • เปิด หน้าติดตั้ง ลองกดปุ่มแฟลชกับชุดของครูเอง 1 ชุดก่อนวันจริง
3 · เครือข่าย

Wi-Fi ของโรงเรียน

  • ชื่อ Wi-Fi (SSID) และรหัสผ่าน เขียนบนกระดานต้องเป็น 2.4 GHz บอร์ดมองไม่เห็นวง 5 GHz
  • เป็นวงที่ใส่รหัสแล้วใช้ได้เลยวงที่ต้องล็อกอินผ่านหน้าเว็บ หรือใช้ชื่อผู้ใช้ + รหัส (WPA2-Enterprise) ใช้ไม่ได้
  • เราเตอร์ไม่บล็อกอุปกรณ์คุยกันเอง (AP isolation ปิด)ถ้าเปิด คอมจะหาบอร์ดไม่เจอในขั้น Kit ID
  • เน็ตออกอินเทอร์เน็ตได้ (บอร์ดส่งค่าขึ้น mqtt.laris.co พอร์ต 1883)
  • ทางสำรอง: เปิด hotspot จากมือถือ 1 เครื่อง (ตั้งเป็น 2.4 GHz) ให้ทั้งห้องใช้ได้
4 · เลขเครื่องและรหัส

ขอจากทีม DustBoy ก่อน

  • ช่วงเลข Kit ID ของห้อง เช่น DBK-001 ถึง DBK-030เลขเดียวกันห้ามซ้ำ 2 เครื่อง ข้อมูลจะตีกัน เขียนเลขติดตัวเครื่องด้วยสติกเกอร์
  • รหัส MQTT ของห้องเรียน 1 รหัส ใช้ร่วมกันทุกเครื่องครูเป็นคนพิมพ์ให้ หรือเขียนบนกระดานแล้วลบ ไม่ต้องให้นักเรียนจด
  • ตารางชื่อเล่น (alias) ที่จะโชว์บนจอ เช่น "ห้อง ป.5/2" (ไม่ใส่ = ใช้เลขเครื่อง)
  • เครื่องที่ยังไม่ใส่รหัส MQTT จะวัดและโชว์บนจอได้ตามปกติ แต่ไม่ส่งข้อมูลขึ้นระบบ

ติดต่อขอเลขและรหัส: ทีม DustBoy Kit (CCDC มหาวิทยาลัยเชียงใหม่)

5 · ในคาบ

ลำดับการสอน (ประมาณ 90 นาที)

  1. ต่อสาย (30 นาที) ดูผังสายจาก README ตรวจ 5V/GND ของ PMS7003 ก่อนเสียบ USB ทุกครั้ง
  2. แฟลช (10 นาที) เสียบ USB → หน้าติดตั้ง → ปุ่ม "แฟลช DustBoy Kit" → เลือกพอร์ต → รอจบ → จอขึ้นค่าฝุ่นทันทีแม้ยังไม่มี Wi-Fi
  3. Wi-Fi (10 นาที) ถอด-เสียบ USB ใหม่ 1 ครั้ง → หน้าตั้งค่า Wi-Fi → เลือกชื่อ Wi-Fi → ใส่รหัส → บอร์ดบอก IP
  4. Kit ID (10 นาที) หน้าเดียวกัน ขั้น 3 → ใส่เลข 001, 002… → ชื่อเล่น → รหัส MQTT จากครู → บันทึก
  5. ดูข้อมูล (20 นาที) เปิด Dashboard ใส่ IP ของเครื่อง เทียบค่าในห้องกับนอกห้อง ลองเป่าควันธูปใกล้ ๆ
  6. เก็บ (10 นาที) เครื่องที่จะวางวัดต่อ เสียบอะแดปเตอร์ไว้ ไม่ต้องตั้งอะไรซ้ำ จำ Wi-Fi และเลขเครื่องได้เอง
6 · ถ้าติด

ปัญหาที่เจอบ่อย

  • กดแฟลชแล้วไม่เห็นพอร์ต → เปลี่ยนสาย USB ก่อน (สายชาร์จอย่างเดียว) แล้วลองพอร์ต USB อื่นของคอม
  • แฟลชค้าง / ขึ้น error → กดปุ่ม BOOT บนบอร์ดค้างไว้ขณะเสียบ USB แล้วแฟลชใหม่ หรือใช้หน้า กู้บอร์ด
  • Wi-Fi ไม่ขึ้นในรายการ → เป็นวง 5 GHz หรืออยู่ไกล ให้ใช้ hotspot มือถือแทน
  • จอโชว์ค่าแต่ Dashboard หาเครื่องไม่เจอ → คอมกับบอร์ดคนละวง Wi-Fi หรือเราเตอร์เปิด AP isolation
  • จอขึ้น "---" หรือค่าไม่เปลี่ยน → PMS7003 ไม่ได้ไฟ 5V หรือสลับสาย TX/RX
