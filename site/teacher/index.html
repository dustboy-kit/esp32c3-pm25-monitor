  • หน้าแรก
  • สำหรับผู้สอน

1อุปกรณ์ (ต่อ 1 ชุด)

  • DustBoy Kit 1 ชุด
  • สาย USB-C "สายข้อมูล" 1 เส้น (สายชาร์จอย่างเดียวใช้แฟลชไม่ได้ ทดสอบก่อนทุกเส้น)
  • อะแดปเตอร์ USB (ที่ชาร์จมือถือ) 1 ตัว ถ้าจะวางเครื่องไว้วัดต่อเนื่องหลังเรียน

2คอมพิวเตอร์ที่ใช้แฟลช

  • คอมพิวเตอร์ Windows / Mac / Linux ที่มี Chrome หรือ Edge (iPad, มือถือ, Safari, Firefox ใช้แฟลชไม่ได้)
  • 1 เครื่องต่อนักเรียน 2–4 คน (แฟลช 1 ชุดประมาณ 2 นาที)
  • คอมพิวเตอร์ต่อ Wi-Fi วงเดียวกับที่เครื่องจะใช้ (ขั้นตั้ง Kit ID คุยกับเครื่องผ่าน Wi-Fi)
  • เปิด หน้าแรก ลองแฟลชชุดของครูเอง 1 ชุดก่อนวันจริง

3Wi-Fi ของโรงเรียน

  • ชื่อ Wi-Fi (SSID) และรหัสผ่าน เขียนบนกระดาน (ต้องเป็น 2.4 GHz เครื่องมองไม่เห็นวง 5 GHz)
  • วงที่ใส่รหัสแล้วใช้ได้เลย (วงที่ล็อกอินผ่านหน้าเว็บ หรือใช้ชื่อผู้ใช้ + รหัส / WPA2-Enterprise ใช้ไม่ได้)
  • เราเตอร์ไม่บล็อกอุปกรณ์คุยกันเอง (AP isolation ปิด) (ถ้าเปิด คอมพิวเตอร์จะหาเครื่องไม่เจอตอนตั้ง Kit ID)
  • ออกอินเทอร์เน็ตได้ตามปกติ (เครื่องส่งค่าขึ้นระบบเอง)
  • ทางสำรอง: hotspot จากมือถือ 1 เครื่อง (ตั้งเป็น 2.4 GHz) ให้ทั้งห้องใช้

4ขอจากทีม DustBoy ก่อน

  • ช่วงเลข Kit ID ของห้อง เช่น DBK-001 ถึง DBK-030 (เลขเดียวกันห้ามซ้ำ 2 เครื่อง เขียนเลขติดตัวเครื่องด้วยสติกเกอร์)
  • รหัสส่งข้อมูลของห้องเรียน 1 รหัส ใช้ร่วมกันทุกเครื่อง (ครูพิมพ์ให้ หรือเขียนกระดานแล้วลบ ไม่ต้องให้นักเรียนจด)
เครื่องที่ยังไม่ใส่รหัส วัดและโชว์บนจอได้ตามปกติ แต่ไม่ส่งข้อมูลขึ้นระบบ

ติดต่อขอเลขและรหัส: ทีม DustBoy Kit (CCDC มหาวิทยาลัยเชียงใหม่)

5ลำดับการสอน (ประมาณ 90 นาที)

  • ประกอบ · 30 นาที ประกอบตามใบในชุด ตรวจว่าทุกสายเสียบแน่นก่อนเสียบ USB
  • แฟลช · 10 นาที เสียบ USB → หน้าแรก → ปุ่ม "แฟลช DustBoy Kit" → เลือกพอร์ต → จอขึ้นค่าฝุ่นทันทีแม้ยังไม่มี Wi-Fi
  • Wi-Fi · 10 นาที ปิดหน้าต่างแฟลช → หน้าตั้งค่า Wi-Fi → เลือกชื่อ Wi-Fi → ใส่รหัส → เครื่องบอก IP
  • Kit ID · 10 นาที หน้าเดียวกัน ขั้น 3 → ใส่เลข 001, 002… → รหัสจากครู → บันทึก
  • ดูข้อมูล · 20 นาที เปิด Dashboard ใส่ IP ของเครื่อง เทียบค่าในห้องกับนอกห้อง ลองเป่าควันธูปใกล้ ๆ
  • เก็บ · 10 นาที เครื่องที่จะวางวัดต่อ เสียบอะแดปเตอร์ไว้ ไม่ต้องตั้งอะไรซ้ำ จำ Wi-Fi และเลขเครื่องได้เอง

6ถ้าติด

อาการทำอะไร
กดแฟลชแล้วไม่เห็นพอร์ตเปลี่ยนสาย USB ก่อน (สายชาร์จอย่างเดียว) แล้วลองพอร์ต USB อื่นของคอมพิวเตอร์
แฟลชค้าง / ขึ้น errorเปลี่ยนสาย/พอร์ต USB แล้วแฟลชใหม่ ถ้ายังไม่ได้ใช้หน้า กู้เครื่อง
Wi-Fi ไม่ขึ้นในรายการเป็นวง 5 GHz หรืออยู่ไกล ใช้ hotspot มือถือแทน
จอโชว์ค่าแต่ Dashboard หาเครื่องไม่เจอคอมพิวเตอร์กับเครื่องคนละวง Wi-Fi หรือเราเตอร์เปิด AP isolation
จอขึ้น "---" หรือค่าไม่เปลี่ยนสายเซนเซอร์หลวม ถอดแล้วเสียบใหม่ให้แน่น
