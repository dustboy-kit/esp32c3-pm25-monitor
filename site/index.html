DustBoy Kit

ติดตั้งเครื่องวัดฝุ่น PM2.5 ของห้องเรียนใน 3 ขั้น ใช้คอมพิวเตอร์ที่มี Chrome หรือ Edge กับสาย USB เส้นเดียว

  • แฟลช
  • ต่อ Wi-Fi
  • ใส่ Kit ID
1

เสียบ USB แล้วแฟลชเฟิร์มแวร์

เสียบเครื่องกับคอมพิวเตอร์ กดปุ่ม แล้วเลือกพอร์ตที่เด้งขึ้นมา รอประมาณ 1 นาที

อยากได้หน้าจอลายอื่น (33 ลาย): เลือกลายแล้วแฟลชจากหน้า Canvas

2

ต่อ Wi-Fi

ปิดหน้าต่างแฟลช แล้วเปิดหน้าตั้งค่า เลือกชื่อ Wi-Fi ของโรงเรียนและใส่รหัส ถ้าหาเครื่องไม่เจอ ให้ถอด-เสียบ USB 1 ครั้ง

เปิดหน้าตั้งค่า Wi-Fi
3

ใส่ Kit ID และรหัสจากครู

อยู่ในหน้าเดียวกับขั้น 2 ใส่ Kit ID DBK-001, DBK-002 … และรหัสที่ครูให้ เครื่องจะเริ่มส่งค่าฝุ่นขึ้นระบบเอง

หลังกดบันทึกในหน้าตั้งค่า Wi-Fi จะมีปุ่ม "ดูค่าฝุ่นสด" ให้กดต่อทันที

ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ (มือถือใช้ไม่ได้) สาย USB ต้องเป็นสายข้อมูล ไม่ใช่สายชาร์จอย่างเดียว
ครูผู้สอน: ต้องเตรียมอะไรบ้างก่อนสอน
