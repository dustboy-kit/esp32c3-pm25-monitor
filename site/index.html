DustBoy Kit

ติดตั้งเครื่องวัดฝุ่น PM2.5 ของห้องเรียนใน 3 ขั้น ใช้คอมที่มี Chrome หรือ Edge กับสาย USB เส้นเดียว

👩‍🏫 ครูผู้สอน: ต้องเตรียมอะไรบ้างก่อนสอน →

ทำตามลำดับ

3 ขั้น จากกล่องถึงค่าฝุ่นบนจอ

พร้อมใช้
1

เสียบ USB แล้วแฟลชเฟิร์มแวร์

เสียบบอร์ดกับคอม กดปุ่ม แล้วเลือกพอร์ตที่เด้งขึ้นมา ใช้เวลาประมาณ 1 นาที บอร์ดทุกเครื่องใช้ไฟล์เดียวกัน

อยากได้หน้าจอลายอื่น (33 ลาย): เลือกลายแล้วแฟลชจากหน้า Canvas ↗
2

ต่อ Wi-Fi

ถอดสายแล้วเสียบใหม่ 1 ครั้ง เปิดหน้าตั้งค่า เลือกชื่อ Wi-Fi ของโรงเรียนแล้วใส่รหัส บอร์ดจะบอก IP กลับมาเมื่อต่อได้

📶 เปิดหน้าตั้งค่า Wi-Fi
3

ใส่ Kit ID และรหัสจากครู

อยู่ในหน้าเดียวกับขั้น 2 ใส่เลขเครื่อง DBK-001, DBK-002 … ชื่อเล่นที่จะโชว์บนจอ และรหัส MQTT ที่ครูให้ เครื่องจะเริ่มส่งค่าฝุ่นขึ้นระบบเอง

ดูค่าฝุ่นสดจากเครื่อง →
